**Status: archived / superseded.** These documents are kept for historical context and are **not** the active plan.

- **Outcome:** Sprint 1 (Foundations) was built and locally verified (30/30 acceptance checks) on 2026-10-12. Sprints 2–6 were specified but not started under this model.
- **Superseded by:** the modular architecture in [`../../modules/README.md`](../../modules/README.md) and the per-module charters `M0`–`M8`.

The project is now developed as **modules** (platform, injector/ingestion, knowledge, and the product legs: quizzes & assessments, lessons/notes, live projects, hackathons & events, thesis/report composer, delivery) rather than time-boxed sprints. Verified constraints and decisions recorded in these files remain useful background but should be read against the module charters.
